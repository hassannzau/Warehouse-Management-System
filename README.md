A Java-based desktop application designed to manage inventory across one or multiple stores and warehouses.

The system allows users to perform the following activities;

Track incoming and outgoing stock.
Manage product inventory and stock levels.
Record sales and restocking transactions.
Generate billing details.
Receive low-stock notifications.
Generate monthly sales reports.
Manage stock distribution between multiple locations.

The main goal is to simplify inventory tracking and help businesses maintain consistent product availability.
